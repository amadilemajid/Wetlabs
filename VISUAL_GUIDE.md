## Feature Interaction Flows

### Search Flow
```
User Types in Search
        ↓
Real-time Filtering
        ↓
Results Displayed
        ↓
User Clicks Result
        ↓
Filter Store Updated
        ↓
Map Automatically Updates
        ↓
Markers Filtered by Selection
```

### Export Flow
```
User Clicks Export
        ↓
Modal Opens
        ↓
User Selects Format (PNG/PDF/CSV)
        ↓
Export Processing
        ↓
File Downloaded
        ↓
Toast Notification
```

### Add Data Flow
```
User Clicks Add Data
        ↓
Modal Opens
        ↓
User Uploads File (GeoJSON/KML)
        ↓
File Validation
        ↓
File Parsing
        ↓
Layer Added to Map
        ↓
Success Notification
```

### AOI Flow
```
User Clicks Set AOI
        ↓
Modal Opens
        ↓
User Selects Mode (Point/Polygon)
        ↓
Modal Closes
        ↓
User Interacts with Map
        ↓
AOI Appears on Map
        ↓
User Can Clear AOI
```
